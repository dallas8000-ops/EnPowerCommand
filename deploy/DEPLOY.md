# Deployment Guide

Platform: **Railway** (via **Deployment-Stripe-center**)

Automation app: [Deployment-Stripe-center](https://stripe-installer-production.up.railway.app/login)  
Project slug: **`enpowercommand`**  
Production URL: https://enpowercommand-production.up.railway.app

## Use the automation app (recommended)

| Step | Action |
|------|--------|
| 1 | Open Deployment-Stripe-center → project **EnPowerCommand** |
| 2 | Vault: `STRIPE_*`, `RAILWAY_API_TOKEN`, `AUTH_SECRET` |
| 3 | **Run full setup** — provisions Stripe, writes `.stripe-installer/stripe-manifest.json` |
| 4 | **Deploy** → env push + Railway deploy |
| 5 | Railway shell once: `npm run db:init` |

CLI:

```powershell
cd "C:\Software Projects\Deployment-Stripe-center\backend"
python manage.py stripe_installer run enpowercommand
python manage.py stripe_installer deploy enpowercommand --push
```

See [`docs/STRIPE-SETUP.md`](../docs/STRIPE-SETUP.md) for Stripe details.

## Config files in this repo

| File | Managed by |
|------|------------|
| `stripe.config.json` | Automation UI / you |
| `deploy.config.json` | Automation UI / you |
| `.stripe-installer/*.json` | Generated by automation pipelines |

## Manual fallback

```powershell
npm run sync:railway-env
```

Preview Railway variables from manifests only — does not replace the automation app.

## Local development

```powershell
npm run db:up
npm run db:init
npm run dev
```

`server/.env`: local Docker Postgres, `DB_SSL=false`, `SKIP_AUTH=true` — never use the Railway production `DATABASE_URL` on your laptop.

## Post-deploy checks

1. https://enpowercommand-production.up.railway.app/api/health (`db: true`)
2. Billing page loads plans from `/api/billing/plans`
3. Stripe webhook: `https://enpowercommand-production.up.railway.app/api/billing/webhook`
